# 仕様との突き合わせ

docs/仕様書.txt の項目ごとに、実装の状態をまとめたもの。✅ 実装済み／🟡 一部または簡易／⬜ 未実装。

## 未実装・一部のもの（対応が必要か判断が要る）
| 項目 | 状態 | 内容 |
|---|---|---|
| No.07 病気 | ⬜ | 仕様で「後のフェーズで定義」としたまま。死亡は老衰とまれな事故、感染は去勢後のみ |
| No.03 労働枠 | 🟡 | 「労働枠は生産に配置できる家畜数を決める」が独立した枠になっていない。搾乳スロットと畑スロットの数が実質の労働枠 |
| No.16 日常イベントの差分 | 🟡 | 仕組みはターン開始時の家畜の仕草1件と、厩務員への話しかけのみ。性格・なつき度・個体関係・担当厩務員による差分、他個体との交流イベントはまだない（文章IDもダミー数件） |
| No.05 生産履歴 | 🟡 | 搾乳量の累計は内部に持つが、個体詳細の履歴には季節ごとの生産が出ない（繁殖・処置・出荷の履歴は出る） |
| No.02 出荷適期の通知（馬） | 🟡 | 牛のみ。馬の出荷適期は仕様に数値がない |
| No.12 高齢の乳牛の減価 | 🟡 | 年齢による一律の減価（16ターン以降）で、乳牛かどうかで分けていない |
| No.20 セーブの書き出し | 🟡 | 共有ページ（claude.ai の公開版）ではファイルのダウンロードが許可されないため動かない。リポジトリ版では動く |
