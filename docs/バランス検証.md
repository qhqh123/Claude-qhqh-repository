# バランス検証（自動プレー）

`node tools/sim.js [回数] [年数]` で再現できます。数値を変えて試すときは `TUNE='{"staffWage":60000}' node tools/sim.js` のようにします。
ゲームの計算部分をそのまま使い、方針の違う自動プレーヤーに遊ばせた結果です。自動プレーヤーは単純な決まりで動くので、人が遊ぶより下手です。傾向を見るためのものです。先輩牧場主の再建支援は使っていません。

## バランスの目標
- 開始時の資源（お金・枠・良い血統）を潤沢にしすぎず、拡張していく楽しみを残す。「1年目はぎりぎり」はこの意味で、返済の可否を厳密に合わせる目標ではない（最終的にはテストプレーで決める）。
- 普通に遊べば黒字で回り、借入を少しずつ返せる。固定費でじわじわ減っていく形にはしない。
- 搾乳スロット・畑スロットは初期投資が要るが、1〜2年で元が取れ、そこからは黒字。
- 乳牛と搾乳がいちばん稼げる（妊娠・泌乳の管理の手間がある分）。
- 農耕馬に商業作物を作らせるのは、利益は低いが手間がなく、馬の寿命から見てほぼ確実に黒字。
- 安い育成牛を買って育てて売るのも、稼ぎ方の一つになる。
- 去勢は標準期がいちばん得（仕様 No.12）。

## 方針
| 方針 | 内容 |
|---|---|
| 何もしない | ターンを進めるだけ |
| 基本 | 雄の仔牛を標準期に委託で去勢、自然交配、搾乳スロットを埋める、6ターンで出荷、繁殖用の雌は受胎できるもの6頭まで（余った若い雌は売る）、「生産なし」になった牛は出荷、種牛が年を取ってきたら雄の仔牛を1頭後継ぎに残す。施設は増やさない |
| 改良と搾乳 | 基本＋人工授精（Aランクのストロー）、直接対応の去勢、搾乳スロット・畑・放牧地を資金に応じて増やす |
| 育成牛を買って育てて売る | 基本＋家畜市場の安い若い雌牛を買い、成熟したら売る |
| 農耕馬で商業作物 | 基本＋馬の放牧地を開き、成馬を買って畑に配置し、商業作物を作らせる |
| 競馬 | 基本＋2年目から競走馬を育ててレースに出す |

## 結果（60回 × 10年。2026-11-25 のまとめ検証）
後天バッジの作り直し（受胎率 ×0.7・雌牛 6→8歳・乳量低下 4歳から上限A）、安い育成牛、畑の数値、先輩牧場主、手伝いを入れたあとの結果。

| 方針 | 1年目に全額返済 | 完済した年（中央値） | 10年で完済 | 10年後の所持金（中央値） |
|---|---|---|---|---|
| 何もしない | 0% | — | 0% | 0（借入 3,566万） |
| 基本 | 93% | 9年目 | 95% | 472万 |
| 改良と搾乳 | 0%（1年目から投資するため） | 7年目 | 100% | 1,245万 |
| 育成牛を買って育てて売る | 100% | 9年目 | 100% | 496万 |
| 農耕馬で商業作物 | 0%（1年目に馬の放牧地を開くため） | 10年目以降 | 48% | 102万 |
| 競馬 | 97% | — | 20% | 0（借入 410万） |

- 前回（後天バッジ導入直後）とほぼ同じ傾向。乳量低下を4歳からにした分、搾乳1枠の稼ぎは 1.4〜1.8年で回収と、ほぼ変わらない。
- 農耕馬の方針は 67% → 48% に下がった（老いた馬の【足腰の衰え】で倍率が落ちるため。自動プレーヤーは馬を入れ替えない）。
- 後天バッジ（受胎率低下・受胎不可）で年を取った牛は子を産めなくなる。「生産なし」の通知に普通に対応すれば（出荷する、若い雌や後継ぎの雄を残す）黒字で回る。

## 施設とお金の流れ（1枠・1ターンあたり）
| 施設・稼ぎ方 | 収入 | 費用 | 元が取れるまで |
|---|---|---|---|
| 搾乳スロット | 約16万 | 維持費 2万 | 増設費 80万 → 約1.5年 |
| 畑（馬なし・牧草） | 飼料 5万分を自給 | 維持費 1万 | 開拓費 30万 → 約1.9年 |
| 畑（農耕馬・商業作物、平凡〜やや優秀） | 約9万 | 馬の飼料 4万・維持費 1万 | 差し引き +4万／ターン。能力の高い馬ほど増える |
| 育成牛 | 購入 平均18万 → 売却 平均40万 | 育成中の飼料 | 1頭あたり十数万円の黒字 |

- 搾乳 ＞ 商業作物 の順になっている。商業作物は低いが安定して黒字。
- 自動プレーヤーは雌牛の数を管理しないと飼育枠が埋まり、出荷が年1頭まで落ちる。増えすぎた雌を売るのが大事。

## フォームごとの維持費1あたりの利益（段5-6。2026-11-25）
`SEED=3 node tools/sim.js 60 10`（と SEED=11）の「フォームごとの維持費1あたりの利益」の節。
全フォームが入荷済みの状態で、最初の家畜をすべて同じフォームにして「基本」の方針で10年遊ぶ（子も同じフォーム）。
利益 = 家畜からの収入（出荷・売却・搾乳・副産物）− 飼料費、維持費 = 飼料費。中央値。

| フォーム | 家畜からの収入 | 飼料費 | 維持費1あたりの利益 | 前のフォームとの比（SEED=3 / 11） |
|---|---|---|---|---|
| 普通 | 3917万 | 1707万 | 1.25 | — |
| テレパシー種 | 3874万 | 1615万 | 1.37 | 1.09 / 1.10 |
| タウル種 | 3810万 | 1533万 | 1.49 | 1.09 / 1.08 |
| 半獣人種 | 3658万 | 1364万 | 1.64 | 1.10 / 1.11 |
| ケモミミ種 | 4448万 | 760万 | 4.78 | 2.92 / 2.89 |

- 順位は normal → telepathy → taur → halfbeast → kemomimi の順に良くなっている。
- 普通〜半獣人種は、各段おおむね1割になるよう、維持費（飼料）の倍率を調整した（`js/consts.js` の `G.FORMS`。0.9／0.8／0.5 → 0.96／0.89／0.78）。
- ケモミミ種は飼育枠を消費せず頭数が増えるため、収支が大きく伸びる（約2.9倍）。指示どおり異常として扱わず、数値は調整していない。

## これまでに変えた数値
- 牧草の基本生産：10 → 25単位（馬なし 0.5倍で 12.5単位）
- 商業作物の基本収益：3万 → 10万円（平凡な農耕馬 1.0倍）
- 家畜市場に、安い若い雌牛（特筆は肉質・伸び/骨格・深み/肉付きのどれか1つ、C ¥15万／B ¥25万）を毎ターン1〜2頭
