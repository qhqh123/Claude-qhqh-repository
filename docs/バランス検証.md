# バランス検証（自動プレー）

`node tools/sim.js [回数] [年数]` で再現できます。数値を変えて試すときは `TUNE='{"staffWage":60000}' node tools/sim.js` のようにします。
ゲームの計算部分をそのまま使い、方針の違う自動プレーヤーに遊ばせた結果です。自動プレーヤーは単純な決まりで動くので、人が遊ぶより下手です。傾向を見るためのものです。先輩牧場主の再建支援は使っていません。

## バランスの目標
- 開始時の資源（お金・枠・良い血統）を潤沢にしすぎず、拡張していく楽しみを残す。「1年目はぎりぎり」はこの意味で、返済の可否を厳密に合わせる目標ではない（最終的にはテストプレーで決める）。
- 普通に遊べば黒字で回り、借入を少しずつ返せる。固定費でじわじわ減っていく形にはしない。
- 搾乳スロット・畑スロットは初期投資が要るが、1〜2年で元が取れ、そこからは黒字。
- 乳牛と搾乳がいちばん稼げる（妊娠・泌乳の管理の手間がある分）。
- 農耕馬に商業作物を作らせるのは、利益は低いが手間がなく、馬の寿命から見てほぼ確実に黒字。
- 安い育成牛を買って育てて売るのも、稼ぎ方の一つになる。
- 去勢は標準期がいちばん得（仕様 No.12）。

## 方針
| 方針 | 内容 |
|---|---|
| 何もしない | ターンを進めるだけ |
| 基本 | 雄の仔牛を標準期に委託で去勢、自然交配、搾乳スロットを埋める、6ターンで出荷、繁殖用の雌は受胎できるもの6頭まで（余った若い雌は売る）、「生産なし」になった牛は出荷、種牛が年を取ってきたら雄の仔牛を1頭後継ぎに残す。施設は増やさない |
| 改良と搾乳 | 基本＋人工授精（Aランクのストロー）、直接対応の去勢、搾乳スロット・畑・放牧地を資金に応じて増やす |
| 育成牛を買って育てて売る | 基本＋家畜市場の安い若い雌牛を買い、成熟したら売る |
| 農耕馬で商業作物 | 基本＋馬の放牧地を開き、成馬を買って畑に配置し、商業作物を作らせる |
| 競馬 | 基本＋2年目から競走馬を育ててレースに出す |
| 新品種を買う | 基本＋家畜市場に並んだ新品種（フォーム）の雌を、新しいフォームほど優先して買う。繁殖用に残すときも新しいフォームを優先し、ケモミミ種の雌は上限に数えず全部残す |

拡張する方針（改良と搾乳・農耕馬・競馬）は、余ったお世話の使い方を3通り試す：使わない（拡張の木材は全部買う）／木こり小屋で木材を貯める（買わない）／手伝いで現金を得て、不足分の木材を買う。

## まとめ検証：フォーム導入の影響（60回 × 12年。2026-11-25）
`SEED=1 node tools/sim.js 60 12`（フォームあり）と、`SEED=1 TUNE='{"formArrival":{}}' node tools/sim.js 60 12`（入荷なし）を比べた。Bルートは対象外。
木材（拡張費用の一部を木材で払う）を入れてから初めての本番の実行でもある。

- フォームを1頭も持たない方針（基本など）でも差が出ているのは、乱数の進み方が変わるため。中央値で±1割ほどは誤差と見る。
- 12年までなら、フォームの入荷で収支はほとんど変わらない。「新品種を買う」も基本と同じくらい（所持金はむしろ少ない）。
  - 市場に並ぶ新品種は少なく（1ターンに雌が1頭前後）、牧場の普通の種牛と交配すると子の半分は普通に戻る。12年目の頭数は、新品種を買う方針でもテレパシー種0.4・タウル種0.6・半獣人種0.7・ケモミミ種2.1頭（1回あたりの平均）。
  - 人工授精・外部種牡馬を使う方針では、カタログのフォームの種雄から自然にフォームの子が入る（各フォーム0.5〜1.8頭）。
- 20年まで延ばすと（`SEED=2 ONLY='基本' node tools/sim.js 60 20`）、新品種を買う方針はケモミミ種が平均35頭まで増え、18年目から年間の収支が基本を上回る（20年目 426万／307万）。ケモミミ種が入荷した後に収支が大きく伸びるのは仕様どおりで、調整していない。
- 木材：拡張する方針では、木こり小屋か手伝い＋購入のどちらでもお世話を使ったほうが、使わない（木材を全部買う）より所持金が多い（改良と搾乳で 2,686万 → 3,6〜3,7千万）。拡張の回数は同じ（18回）。
- 競馬の方針は、どの使い方でも後半に赤字になる（前回と同じ傾向。木こり小屋の場合が最も悪い：木材を貯めるあいだ手伝いをせず、借入が膨らむ）。

### ブラウザでの通し確認（Aルート、21項目）
新規ゲームから画面でターンを進め、フォームに関わる流れを確かめた。ゲームのエラーは0件。
- 開始時はフォームなし。3・5・7・9年目に入荷し、「家畜市場に新しい品種が入りました」の通知がそれぞれ1回。11年目まで増えない

- テレパシー種の去勢で声が4か所（話者名は個体名）、経過日誌にも声。普通の個体には声・腕・二足の文が出ない

- 去勢の窓で委託を選ぶと獣医の1行
- タウル種の出荷：選ぶまで出荷できない、「副産物　ペットフード原料　¥21,000」、収支の分類

- セーブ・ロードでフォームが保たれ、古いセーブは普通・Aルートとして読む
- 日常イベントで声のある個体に声の行。下絵スキンへの切り替え、スマホ幅の市場

## 結果（60回 × 10年。2026-11-25 のまとめ検証）
後天バッジの作り直し（受胎率 ×0.7・雌牛 6→8歳・乳量低下 4歳から上限A）、安い育成牛、畑の数値、先輩牧場主、手伝いを入れたあとの結果。

| 方針 | 1年目に全額返済 | 完済した年（中央値） | 10年で完済 | 10年後の所持金（中央値） |
|---|---|---|---|---|
| 何もしない | 0% | — | 0% | 0（借入 3,566万） |
| 基本 | 93% | 9年目 | 95% | 472万 |
| 改良と搾乳 | 0%（1年目から投資するため） | 7年目 | 100% | 1,245万 |
| 育成牛を買って育てて売る | 100% | 9年目 | 100% | 496万 |
| 農耕馬で商業作物 | 0%（1年目に馬の放牧地を開くため） | 10年目以降 | 48% | 102万 |
| 競馬 | 97% | — | 20% | 0（借入 410万） |

- 前回（後天バッジ導入直後）とほぼ同じ傾向。乳量低下を4歳からにした分、搾乳1枠の稼ぎは 1.4〜1.8年で回収と、ほぼ変わらない。
- 農耕馬の方針は 67% → 48% に下がった（老いた馬の【足腰の衰え】で倍率が落ちるため。自動プレーヤーは馬を入れ替えない）。
- 後天バッジ（受胎率低下・受胎不可）で年を取った牛は子を産めなくなる。「生産なし」の通知に普通に対応すれば（出荷する、若い雌や後継ぎの雄を残す）黒字で回る。

## これまでに変えた数値
- 牧草の基本生産：10 → 25単位（馬なし 0.5倍で 12.5単位）
- 商業作物の基本収益：3万 → 10万円（平凡な農耕馬 1.0倍）
- 家畜市場に、安い若い雌牛（特筆は肉質・伸び/骨格・深み/肉付きのどれか1つ、C ¥15万／B ¥25万）を毎ターン1〜2頭
