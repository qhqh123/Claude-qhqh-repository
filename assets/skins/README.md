# スキン（家畜と人物の絵の差し替え）

ゲームの絵は「スキン」として丸ごと差し替えられます。

- **標準**：プログラムで描く絵（`js/draw.js`, `js/draw-horse.js`）。画像がないところは、いつもこの絵で描きます。
- **画像スキン**：このフォルダの下に、決まった名前のPNGを置いたもの。
- **下絵**（`template/`）：標準の絵をそのまま画像に書き出したもの。なぞったり、同じ大きさで描き直したりする元になります。

## 新しいスキンの作り方

1. `template/` をコピーして、新しいフォルダを作る（例：`assets/skins/watercolor/`）。
2. 画像を描き直す。**ファイル名・画像の大きさ・足元の位置は下絵と同じ**にする。
   - 一部だけ描き直してもかまいません。置かなかった（消した）画像は、標準の絵で表示されます。
3. `node tools/skin-files.js` を実行して、置いた画像の一覧（`assets/skins/files.js`）を作り直す。
   ゲームはこの一覧にある画像だけを読みます。画像を足したり消したりしたら、毎回実行します。
4. `assets/skins/index.js` の `list` に1つ足す（`template` の項目をコピーして、`label` と `dir` を変える）。
5. ゲームのメニューで開発者モードを入れ、「スキン」のボタンで切り替える（ブラウザに記憶されます）。
   最初から使うなら `index.js` の `active` をそのスキンの名前にする。

下絵を作り直すとき（標準の絵を変えたときなど）は `node tools/export-skin.js` を実行します。

## フォーム（同じ種の別の見た目）

個体は「フォーム」を持ちます。今の牛・馬は `normal` です。別のフォーム（例：`highland`）の絵を用意するときは、
ファイル名の `<種>` の部分を `<種>-<フォーム>` にします（例：`cattle-highland_adult_coat0_walk.png`）。
そのフォームの画像がない部分は、その種の標準の絵（プログラムで描く絵）で表示されます。
フォームは `normal`（普通）・`telepathy`（テレパシー種）・`taur`（タウル種）・`halfbeast`（半獣人種）・`kemomimi`（ケモミミ種）です。
二足歩行の `halfbeast` と `kemomimi` は、歩き絵の枠が縦長です（`index.js` の `sprite` に `cattle-halfbeast` などで枠の大きさを書きます）。

## 画像の決まり

背景は透明。拡大縮小はゲーム側でするので、下の大きさのまま描きます。

### マップの家畜：`<種>_<成長段階>_coat<毛色>_<動き>.png`

- 種：`cattle`（牛）・`horse`（馬）
- 成長段階：`calf`（仔）・`young`（若）・`adult`（成）
- 毛色：`0`〜`4`
- 動き：`walk`（歩き、4コマ）・`idle`（立ち止まり、1コマ）・`graze`（草を食む、1コマ）

| 種 | 1コマの大きさ | 足元の位置（コマの中） |
|---|---|---|
| 牛 | 128×96 | 横 64・縦 90 |
| 馬 | 128×112 | 横 64・縦 106 |

- コマは横に並べます（歩きは 512×96 など）。
- **右向き**で描きます。左向きはゲームが反転して作ります。
- 仔牛や若い牛は、同じコマの大きさの中に小さく描きます（大きさの違いは絵で表す）。
- 影も絵に含めます。

### 立ち絵（重ね合わせ）：512×512

下から順に重ねます。

| 層 | ファイル名 | 内容 |
|---|---|---|
| 角 | `cattle_horns_small.png`／`cattle_horns_big.png` | 牛の角（成熟した未去勢の雄は big、それ以外の若牛・成牛は small、仔牛はなし） |
| 顔と体 | `<種>_coat<毛色>_base.png` | 毛色ごとの顔・耳・体 |
| 表情 | `<種>_expr_<表情>.png` | 目・口・ほっぺ。種ごとに共通 |
| 表情（毛色ごと・任意） | `<種>_coat<毛色>_expr_<表情>.png` | 黒い毛色で目の色を変えたいときなど。あればこちらが使われる |

表情は性格で決まります：`calm`（おっとり）・`sweet`（甘えん坊）・`lively`（活発）・`curious`（好奇心旺盛）・`easy`（マイペース）・`stubborn`（頑固）。

背景のグラデーションはゲームが描くので、立ち絵の画像には描きません。

### 人物：`person_<人>_<動き>.png`、`person_<人>_portrait.png`

- 人：`player`（プレイヤー）・`girl`（厩務員ガール）・`boy`（厩務員ボーイ）・`senior`（先輩牧場主）
- マップ：1コマ 64×96、足元は横 32・縦 92。`walk`（4コマ）と `idle`（1コマ）。右向き。
- 顔（事務所・町の丸い枠）：`person_<人>_portrait.png` 512×512。背景も含めて描きます。

## 注意

- 標準の絵は個体ごとに模様の位置が少しずつ違いますが、画像スキンでは同じ毛色なら同じ絵になります。
- 共有ページ（`tools/build-artifact.py` で作る1ファイル版）は画像を含められないため、標準の絵だけになります。
